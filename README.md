## Run an exercise

Install Python 3 and Git, then clone the repository:

```bash
git clone https://github.com/jvd1990/python-fundamentals.git
cd python-fundamentals
```

Choose a `.py` file from a topic folder and run it with its actual relative path:

```bash
python3 <topic-folder>/<script-name>.py
```

Replace the placeholders with an existing folder and filename. On Windows, use `py` if `python3` is unavailable. For interactive exercises, follow the prompts in the terminal.
